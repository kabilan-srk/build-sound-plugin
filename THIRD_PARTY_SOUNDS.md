# Sounds

The two sounds that Build Sound plays are **original work**. They contain no third-party material: no
recording, no sample, no library, and nothing downloaded.

| File | What it is |
|---|---|
| `src/main/webapp/sounds/success.wav` | Soft two-note chime, G5 then C6, about 0.9 seconds |
| `src/main/webapp/sounds/problem.wav` | Low soft bell, G4 then E4, about 1.45 seconds |

Both files are generated by the script [`tools/make_sounds.py`](tools/make_sounds.py). It calculates every sample
from sine waves using only the Python standard library, and has no randomness, so running it again gives
the same files byte for byte.

To check that the files in the repository really come from the script:

```
python3 tools/make_sounds.py /tmp/regenerated
shasum -a 256 /tmp/regenerated/*.wav src/main/webapp/sounds/*.wav
```

The checksums of each pair must be identical:

```
fe26bffce08f79c1f91506e576f094f87cbc727cb1ba62a389ffad498fdd53d9  success.wav
4a08e6ba4799e9eb9eab0fed69a31bd9b388229859919337789d1d88fa095580  problem.wav
```

The script is a development tool only. It lives outside `src/` and is not packaged into the plugin.
